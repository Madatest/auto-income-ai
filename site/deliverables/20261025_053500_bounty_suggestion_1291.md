## 📌 1. Contexte Réel & Spécification du Problème

Dans le serveur **S.P.L.U.R.T-tg** (basé sur le moteur BYOND / Dream Maker et l'architecture TGstation), certaines zones comme le *Ghost Café* et les *Infinidorms* contiennent des objets uniques, récréatifs ou puissants (trays de chirurgie, matériaux précieux, épées d'énergie, etc.). Actuellement, bien qu'il soit contre les règles du serveur de contrebander ces objets hors de ces zones, il n'existe pas de garde-fou au niveau du code.

**Demande de la communauté (#1291 / #1327) :**
1. Ajouter une variable booléenne `ghost_cafe_only` sur `/obj` (ou au niveau de la classe de base des objets dans BYOND DM).
2. Détecter lorsqu'un objet marqué avec `ghost_cafe_only = TRUE` quitte le périmètre autorisé (Ghost Café ou Infinidorms).
3. Supprimer immédiatement l'objet (`qdel(src)`) de la partie dès qu'il est déplacé ou tiré (*pulled/carried*) en dehors des zones autorisées, accompagné d'un effet visuel/sonore de disparition.

## 🔬 2. Analyse de Cause Racine (Root Cause Analysis)

1. **Absence de contrôle géographique sur la possession d'objets** : Les objets dans DM héritent de `/obj`. Par défaut, `Moved()` sur `/obj` met à jour les coordonnées sans vérifier si la zone actuelle (`/area`) possède un trait/flag spécifique restreignant l'accès aux objets récréatifs du Ghost Café.
2. **Manque de drapeaux d'aire dédiée** : Les zones de type `/area/ghost_cafe` ou `/area/infinidorms` ne disposent pas d'un attribut explicite ou d'un flag d'aire (`AREA_GHOST_CAFE_PERMITTED` ou vérification `is_ghost_cafe`) permettant un contrôle rapide lors des déplacements.
3. **Maniabilité par la cartographie (Mapping)** : Les mappeurs doivent pouvoir définir `ghost_cafe_only = TRUE` directement dans StrongDMM ou SpacemanDMM sur n'importe quelle instance d'objet sans écrire de sous-type spécifique.

## 💻 3. Implémentation & Code de Résolution Proposé

Voici le patch BYOND DM s'intégrant directement au codebase TGstation / SPLURT-tg.

### Modifications apportées :
1. Ajout de `ghost_cafe_only = FALSE` sur `/obj`.
2. Définition du flag ou proc `is_ghost_cafe_zone()` sur `/area`.
3. Interception dans `/obj/Moved()` pour supprimer l'objet s'il franchit la limite.

```dm
// code/modules/admin/ghost_cafe.dm ou code/game/objects/objs.dm

/area
	/// Variable identifiant si l'aire fait partie du complexe Ghost Cafe ou Infinidorms
	var/ghost_cafe_zone = FALSE

/area/ghost_cafe
	ghost_cafe_zone = TRUE

/area/infinidorms
	ghost_cafe_zone = TRUE

/obj
	/// Si TRUE, cet objet s'autodétruit s'il est emmené hors du Ghost Cafe / Infinidorms
	var/ghost_cafe_only = FALSE

/obj/Moved(atom/old_loc, dir, forced = FALSE, list/old_locs)
	. = ..()
	if(!ghost_cafe_only || !loc)
		return

	var/area/current_area = get_area(src)
	if(!current_area || current_area.ghost_cafe_zone)
		return

	// L'objet est sorti de la zone autorisée : dissipation
	var/turf/T = get_turf(src)
	if(T)
		T.visible_message(
			span_warning("[src] scintille brièvement et se dissipe dans l'éther!"),
			vision_distance = COMBAT_MESSAGE_RANGE
		)
		do_sparks(3, FALSE, T)

	qdel(src)
```
