## 📌 1. Contexte Réel & Spécification du Problème

Le runtime `relayhop/sn-monetization-runtime` ingère et agrège les opportunités de monétisation issues des flux de radar Stacker News (SN). Lors de la réception de notifications radar formatées sous forme de lignes tabulées (TSV) transportant les tags `OPEN_BOUNTY`, le système actuel souffre de ruptures de parsing et d'omissions de traitement :

1. **Ingestion déficiente des flux Stacker News (`OPEN_BOUNTY`)** : Le parseur radar ne gère pas la structure tabulée spécifique contenant l'ID d'élément, le territoire/sub (ex: `gaming`, `Stacker_Sports`), le nombre de commentaires, les sats récompensés, le score d'opportunité, ainsi que la liste pipe-délimitée de flux (`recent@gaming|top@gaming|...`).
2. **Défaut de conversion et d'attribution de valeur** : Les montants de recompense exprimés en satoshis (ex: `2100 sats`) ne sont ni extraits ni convertis de manière sécurisée en structures monétisables standardisées au sein de la boucle d'exécution du runtime.
3. **Absence de filtrage d'auto-post et de déduplication** : Les opportunités marquées `SELF_POST_OPP` nécessitent une classification explicite afin d'éviter la ré-exécution d'actions de monétisation en boucle sur ses propres contenus.

Le besoin impératif est de fournir un parseur structuré, résilient et typé capable de transformer ces événements radar en enregistrements de monétisation validés prêts pour la boucle d'exécution du runtime.

## 🔬 2. Analyse de Cause Racine (Root Cause Analysis)

Après inspection du composant d'ingestion des télémétries radar :

- **Absence de Handler pour le schéma TSV SN-Radar** : La fonction d'ingestion s'attendait à un objet JSON structuré direct, alors que les paquets de télémétrie radar sont émis sous forme de chaînes tabulées brutes issues des scripts de scraping SN (`<id>\t<sub>\t<comments>\t<sats>\t<bounty_sats>\t...`).
- **Parsing Incomplet des Tags & Attributs** : Les tags multiples combinés (`OPEN_BOUNTY,HOT,SELF_POST_OPP`) étaient traités comme une simple chaîne opaque sans décomposition vectorielle, empêchant le système de routage de détecter les priorités `HOT` ou d'exclure/marquer les `SELF_POST_OPP`.
- **Analyse Syntaxique Fragile du Titre** : La valeur `bounty_sats` figurait à la fois dans une colonne dédiée et dans le texte explicatif (ex: `2,100 sats`). Le runtime ne rapprochait pas ces données pour valider l'intégrité de l'offre.

## 💻 3. Implémentation & Code de Résolution Proposé

Voici l'implémentation du parseur et gestionnaire d'événements `SNBountyRadarParser` dans `sn_monetization_runtime/radar/sn_bounty_parser.py` :

```python
import re
from dataclasses import dataclass, asdict
from typing import List, Optional, Dict, Any

@dataclass(frozen=True)
class SNBountyItem:
    item_id: int
    sub_territory: str
    comment_count: int
    upvotes: int
    bounty_sats: int
    score: float
    rank_score: float
    author_id: int
    views: int
    channels: List[str]
    tags: List[str]
    title: str
    is_self_post: bool

class SNBountyRadarParser:
    """Parseur robuste pour les télémétries d'open bounty Stacker News (SN)."""

    @staticmethod
    def parse_line(line: str) -> Optional[SNBountyItem]:
        line = line.strip()
        if not line or line.startswith("#"):
            return None

        parts = line.split("\t")
        if len(parts) < 11:
            return None

        try:
            item_id = int(parts[0])
            sub_territory = parts[1].strip()
            comment_count = int(parts[2])
            upvotes = int(parts[3])
            bounty_sats = int(parts[4])
            score = float(parts[5])
            rank_score = float(parts[6])
            author_id = int(parts[7])
            views = int(parts[8])
            channels = [c.strip() for c in parts[9].split("|") if c.strip()]
            tags = [t.strip() for t in parts[10].split(",") if t.strip()]
            title = parts[11].strip() if len(parts) > 11 else ""

            is_self_post = "SELF_POST_OPP" in tags

            return SNBountyItem(
                item_id=item_id,
                sub_territory=sub_territory,
                comment_count=comment_count,
                upvotes=upvotes,
                bounty_sats=bounty_sats,
                score=score,
                rank_score=rank_score,
                author_id=author_id,
                views=views,
                channels=channels,
                tags=tags,
                title=title,
                is_self_post=is_self_post,
            )
        except (ValueError, IndexError):
            return None

    @classmethod
    def parse_batch(cls, raw_payload: str) -> List[SNBountyItem]:
        items = []
        for line in raw_payload.strip().splitlines():
            item = cls.parse_line(line)
            if item and "OPEN_BOUNTY" in item.tags:
                items.append(item)
        return items
```
