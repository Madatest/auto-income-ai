## 📌 1. Contexte Réel & Spécification du Problème

Le composant `sn-monetization-runtime` capture les opportunités de monétisation issues de Stacker News (SN) via des signaux radar automatisés. Lors de l'émission de signaux d'alertes d'opportunités (`OPEN_BOUNTY`), le flux radar transmet des enregistrements TSV (Tab-Separated Values) enrichis contenant des métadonnées de publication, le montant de la prime en *sats*, ainsi que des drapeaux de qualification (`OPEN_BOUNTY`, `HOT`, `SELF_POST_OPP`).

Actuellement, le module d'ingestion radar échoue ou omet le parsing lorsqu'un enregistrement contient :
1. Des chaînes de flux d'origine multiples séparées par des pipes (`recent@gaming|top@gaming|recent@Stacker_Sports`).
2. Une liste de drapeaux de qualification sous forme de valeurs séparées par des virgules (`OPEN_BOUNTY,HOT,SELF_POST_OPP`).
3. Des caractères spéciaux UTF-8 (emojis comme 🏈) dans le titre de la publication Stacker News.

En conséquence, les événements radar ne sont pas correctement sérialisés dans le pipeline de calcul de monétisation, empêchant le runtime de déclencher la réservation automatique et l'attribution des primes.

---

## 🔬 2. Analyse de Cause Racine (Root Cause Analysis)

Après inspection du module `src/radar/bounty-parser.ts`, la cause racine de la défaillance découle de trois facteurs principaux :

1. **Splitting Naïf des Colonnes TSV** : Le résolveur actuel applique un découpage strict par espace au lieu d'un parsing TSV tolérant qui préserve les titres contenant des espaces ou des émojis Unicode.
2. **Échec de Décomposition des Flags & Feeds** : Les attributs `flags` et `feeds` sont traités comme de simples chaînes scalaires sans désérialisation. La recherche de clés comme `OPEN_BOUNTY` ou `SELF_POST_OPP` via sous-chaîne stricte produit des faux négatifs lorsque les combinaisons de flags varient.
3. **Absence de Sanitization pour le Montant des Sats** : La colonne de prime (`sats`) subit une conversion directe `parseInt()` sans fallback ni vérification de bornes, entraînant un comportement instable en cas d'en-tête mal aligné.

## 💻 3. Implémentation & Code de Résolution Proposé

Voici la solution de correctif de production dans `src/radar/bounty-parser.ts` pour parser et valider les télémétries radar SN avec résilience totale.

```typescript
// src/radar/bounty-parser.ts

export interface SnBountyOpportunity {
  id: number;
  sub: string;
  commentsCount: number;
  satsCount: number;
  bountySats: number;
  boostCount: number;
  score: number;
  userId: number;
  postId: number;
  feeds: string[];
  flags: string[];
  title: string;
  isSelfPostOpp: boolean;
}

export class SnBountyRadarParser {
  static parseLine(line: string): SnBountyOpportunity | null {
    if (!line || !line.trim()) return null;

    const parts = line.trim().split(/\t+/);
    if (parts.length < 12) return null;

    const [
      rawId, sub, rawComments, rawSats, rawBounty,
      rawBoost, rawScore, rawUserId, rawPostId,
      rawFeeds, rawFlags, ...titleParts
    ] = parts;

    const id = parseInt(rawId, 10);
    const bountySats = parseInt(rawBounty, 10);

    if (isNaN(id) || isNaN(bountySats)) return null;

    const feeds = rawFeeds ? rawFeeds.split('|').map(f => f.trim()).filter(Boolean) : [];
    const flags = rawFlags ? rawFlags.split(',').map(f => f.trim()).filter(Boolean) : [];
    const title = titleParts.join(' ').trim();

    return {
      id,
      sub,
      commentsCount: parseInt(rawComments, 10) || 0,
      satsCount: parseInt(rawSats, 10) || 0,
      bountySats,
      boostCount: parseInt(rawBoost, 10) || 0,
      score: parseFloat(rawScore) || 0.0,
      userId: parseInt(rawUserId, 10) || 0,
      postId: parseInt(rawPostId, 10) || 0,
      feeds,
      flags,
      title,
      isSelfPostOpp: flags.includes('SELF_POST_OPP'),
    };
  }

  static parseBatch(tsvPayload: string): SnBountyOpportunity[] {
    return tsvPayload
      .split('\n')
      .map(line => this.parseLine(line))
      .filter((item): item is SnBountyOpportunity => item !== null);
  }
}
```

import { SnBountyRadarParser } from '../../src/radar/bounty-parser';

describe('SnBountyRadarParser', () => {

    expect(parsed?.id).toBe(1596567);
    expect(parsed?.sub).toBe('gaming');
    expect(parsed?.bountySats).toBe(2100);
    expect(parsed?.feeds).toEqual(['recent@gaming', 'top@gaming', 'recent@Stacker_Sports']);
    expect(parsed?.flags).toEqual(['OPEN_BOUNTY', 'HOT', 'SELF_POST_OPP']);
    expect(parsed?.isSelfPostOpp).toBe(true);
    expect(parsed?.title).toBe('🏈 Sunday Leaders Bounty • 2,100 sats');
  });

  it('should parse batch TSV input resiliently', () => {

  });
